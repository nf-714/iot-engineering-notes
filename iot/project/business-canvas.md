# Business Model Canvas

## 1. Customer Segments

- Families with elderly parents living at home
- Caregivers who need remote monitoring support
- Small clinics or community health workers
- Elderly patients who need medicine and safety monitoring

## 2. Value Propositions

- Low-cost elderly monitoring solution
- Combines health monitoring and fall detection in one wearable
- Helps reduce worry for family members
- Supports medicine adherence through a smart medicine box
- Real-time alerts and live dashboard visibility
- Faster emergency awareness through MQTT-based data delivery
- More affordable than many imported smart health products

## 3. Channels

- Direct demo to teachers, project judges, and potential users
- Social media promotion
- University project showcase
- Community clinics or local healthcare partners
- Web-based dashboard access

## 4. Customer Relationships

- Simple onboarding through sign-in and device registration
- Dashboard-based self-service monitoring
- Live status visibility for guardians without needing repeated refresh
- Notification-based updates for guardians
- Support through documentation and setup instructions

## 5. Revenue Streams

For the student project phase:

- academic demonstration
- prototype validation
- no immediate revenue required

For future commercialization:

- one-time hardware package sale
- installation and setup fee
- monthly monitoring subscription
- premium alerting or analytics service

## 6. Key Resources

- ESP32 development boards
- `MAX30102`, `MPU6050`, and temperature sensor
- medicine box components such as buzzer, LED, and box enclosure
- laptop for gateway and backend
- MQTT broker, backend API, database, and dashboard software
- team knowledge in IoT, web development, and embedded systems

## 7. Key Activities

- hardware design and prototyping
- firmware development for wearable and medicine box
- backend API and MQTT integration development
- database and dashboard development
- alert logic implementation
- device testing and calibration
- user demo preparation

## 8. Key Partners

- electronics parts suppliers
- local online hardware shops
- university lab or project supervisors
- internet or SMS service providers
- possible healthcare advisers for feedback

## 9. Cost Structure

- wearable hardware cost
- medicine box hardware cost
- rechargeable battery and charging modules
- casing and assembly materials
- internet and optional SMS cost
- network setup for live device communication
- software hosting if moved beyond local laptop deployment

## Summary

The strongest business idea behind ElderCare IoT is affordable remote care for elderly family members. The project creates value by combining safety monitoring, health data, medicine support, and live alerts into a low-budget system that can be built and demonstrated locally.
