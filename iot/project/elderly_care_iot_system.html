Heart rate + SpO2 monitoring
MAX30102 reads every 5 seconds. Alerts if HR <50 or >120 bpm, or SpO2 drops below 94%.
Body temperature
DS18B20 waterproof sensor. Fever alert above 38°C. Hypothermia alert below 35°C.
Fall detection (wearable)
MPU6050 detects sudden acceleration spike + stillness. TinyML threshold model on ESP32. No camera needed.
SOS panic button
Large button on wearable. One press → instant SMS to all family + push notification.
Medicine reminder
RTC-scheduled buzzer + LED flash at dose times. Servo unlocks correct compartment.
Missed dose alert
Reed switch detects if compartment was not opened. Notifies guardian after 15 min grace period.
Real-time dashboard
Live vitals, fall events, medicine log. Colour-coded status (green / yellow / red). Accessible from any device.
Historical trend charts
72-hr HR, temperature, and SpO2 charts. Pattern visibility for doctor consultations.
Multi-guardian SMS alerts
Twilio sends to son, daughter, or caregiver simultaneously. Message includes event type + timestamp.
Offline local buffering
Raspberry Pi stores last 24h of data locally. No data loss if WiFi drops.
